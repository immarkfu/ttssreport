# TTSS Report 运维脚本

本目录存放项目日常运维所需的脚本，需在**应用服务器**（`115.190.232.185`）上执行。

## backfill.sh — 数据补拉脚本

用于修复数据缺口：补拉 tushare 行情数据，并自动触发 B1 信号补算。

### 适用场景

- 服务中断后数据出现缺口（如服务器重启、定时任务失败）
- 初始化部署后需要补全历史数据
- 手动触发某个日期的数据重新计算

### 使用方法

```bash
# 登录应用服务器
ssh root@115.190.232.185

# 进入项目目录
cd /root/ttssreport   # 或实际部署目录

# 自动补全到昨天（推荐日常使用）
bash scripts/backfill.sh

# 补拉指定日期区间
bash scripts/backfill.sh 20260213 20260311

# 只补拉某一天
bash scripts/backfill.sh 20260312 20260312
```

### 注意事项

| 事项 | 说明 |
|------|------|
| 数据可用时间 | tushare 行情数据在每个交易日 **17:30** 后才可用，当天数据请勿补拉 |
| 执行耗时 | 每个交易日约 30-60 秒（含 bak_daily + stk_factor_pro + B1 信号） |
| 重复执行 | 脚本支持幂等，重复执行同一日期会更新已有数据 |
| 容器依赖 | 需要 `ttssreport-backend` 容器处于运行状态 |

### 定时任务说明

后端服务已内置每日定时任务，**每天 20:35** 自动执行当日数据落库和 B1 信号计算，无需手动干预。仅在数据出现缺口时才需要使用此脚本手动补拉。
